# Dipesh Prasad Shrestha — Portfolio (Local)

This repository contains a single-page portfolio website scaffold designed for a multidisciplinary technology profile (software development, data, AI and creative technology).

Quick start (view locally):

1. Open the folder in a code editor or use a simple static server. For example, using Python 3:

```bash
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

2. The `index.html` is the main file. Edit content and replace placeholders such as social links and profile photo under `assets/images`.

Security note: The contact form is a secure stub and does not forward messages. Connect a backend endpoint or use a service (Formspree, Netlify Forms, etc.) and never include private API keys in client-side code.
